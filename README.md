# Ralleur Pages compatibility routes

This repository retains the former kurtz product-page URLs after the Vela →
kurtz rename. `/Vela/`, `/Vela/credits.html` and `/Vela/privacy.html` redirect to
the corresponding current product pages. It does not replace project sites or
change their hosting. No custom domain, tracking, credentials or media are used.
The old GitHub repository name remains reserved by GitHub’s automatic redirect;
creating another Vela repository would break historical repository/download links.
